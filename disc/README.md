# disc/

Place your own dump of **King's Field II (NTSC-U, `SLUS-00255`)** here — the
North American release of the Japanese *King's Field III*. The US "King's Field"
(`SLUS-00158`, the Japanese *King's Field II*) is a different game; that one is
Verdite2.

**Cue/bin:**

```
disc/KingsField3.cue
disc/KingsField3.bin
```

A CHD can be extracted with
`chdman extractcd -i "<image>.chd" -o KingsField3.cue -ob KingsField3.bin`.

Nothing in this directory is committed except this README (see `.gitignore`), and
no game data is distributed with this project.
